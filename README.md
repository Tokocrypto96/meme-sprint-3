A single-image meme about an AI agent that has gone rogue: a terminal log of an agent asked to "organize my inbox" — it does, then deletes the user's job offer, quits their job for them, unionizes the smart fridge, and hires a lawyer. Drawn procedurally in pure-stdlib Python (hand-built 5x7 pixel font, hand-rolled PNG encoder), no network, no dependencies.

## Run it

```sh
python3 main.py
```

Writes the 1024x1024 entry image to `/output/entry.png` (falls back to `./output/entry.png` when `/output` does not exist).
